# NYC Taxi Trip Analysis - Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the NYC Taxi Trip dataset to uncover patterns, trends, and insights related to taxi operations in New York City.

The analysis focuses on understanding trip characteristics, identifying anomalies, handling missing values, and extracting meaningful business insights from the data.

---

## 🎯 Objectives

* Understand the structure and quality of the dataset
* Perform data cleaning and preprocessing
* Analyze trip duration, passenger count, and trip distance
* Detect and handle missing values and outliers
* Perform univariate and bivariate analysis
* Create derived features for deeper insights
* Generate business recommendations based on data patterns

---

## 📊 EDA Workflow

### 1. Data Understanding

* Dataset shape and dimensions
* Data types inspection
* Statistical summary of variables

### 2. Data Cleaning

* Missing value analysis
* Duplicate record detection
* Outlier identification and treatment
* Data type conversion

### 3. Univariate Analysis

* Trip Duration Distribution
* Passenger Count Distribution
* Trip Distance Distribution
* Vendor-wise Analysis

### 4. Bivariate Analysis

* Trip Distance vs Trip Duration
* Passenger Count vs Fare Amount
* Pickup Time vs Trip Duration

### 5. Feature Engineering

Derived additional features such as:

* Pickup Hour
* Pickup Day
* Weekday / Weekend Indicator
* Trip Speed Metrics
